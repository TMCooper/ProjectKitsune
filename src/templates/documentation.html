Données d'Animés

GET/api/topanime

Récupère une liste des animés les mieux classés selon les données de Jikan API.

GET/api/getinfoByid

Récupère un ensemble complet d'informations pour un animé spécifique via son ID MyAnimeList.

Paramètres

NomTypeRequisDescription
idEntierOuiL'ID unique de l'animé sur MyAnimeList.

Exemple de Requête

/api/getinfoByid?id=52991

Réponse (200 OK)

{
    "anime_url": "https://myanimelist.net/anime/52991/Sousou_no_Frieren",
    "title": "Sousou no Frieren",
    "title_english": "Frieren: Beyond Journey's End",
    "episodes_number": 28,
    "status": "Finished Airing",
    "age_restriction": "PG-13 - Teens 13 or older",
    "rank": 1,
    "synopsis": "The story follows the elven mage Frieren...",
    "studios_name": ["Madhouse"],
    "genres_name": ["Adventure", "Drama", "Fantasy"],
    "image_jpg_big": "https://cdn.myanimelist.net/images/anime/1015/138006l.jpg"
}

Réponse d'Erreur (400 Bad Request)

{"error": "Paramètre 'id' manquant"}
GET/api/getAnimeSearch

Effectue une recherche "floue" (fuzzy search) pour trouver des animés correspondant à une chaîne de caractères. Le tri est optimisé pour la pertinence.

Paramètres

NomTypeRequisDescription
qChaîneOuiLe terme de recherche.
lEntierNonLimite le nombre de résultats. Défaut : 5.

Exemple de Requête

/api/getAnimeSearch?q=Frieren&l=3

Réponse (200 OK)

[
    {
        "id": 52991,
        "image_jpg": "https://cdn.myanimelist.net/images/anime/1015/138006.jpg",
        "score": 105.55,
        "title": "Sousou no Frieren"
    },
    ...
]
GET/api/getAnimeNameToInfo

Un endpoint de commodité qui effectue une recherche et retourne directement les informations complètes du premier résultat.

Paramètres

NomTypeRequisDescription
qChaîneOuiLe nom de l'animé à rechercher.

Exemple de Requête

/api/getAnimeNameToInfo?q=Steins;Gate

Données Temporelles

GET/api/getCurrentOut

Liste les animés diffusés un jour spécifique de la semaine.

Paramètres

NomTypeRequisDescription
dayChaîneOuiJour de la semaine en français et minuscules (lundi, mardi...).

Exemple de Requête

/api/getCurrentOut?day=vendredi
GET/api/getSeasonOut

Récupère la liste des animés pour une saison, une année et un type donnés.

Paramètres

NomTypeRequisDescription
yEntierOuiAnnée de diffusion (ex: 2023).
seasonsChaîneOuiSaison en français (printemps, ete, automne, hiver).
typageChaîneNonType d'animé (tv, movie, ova...). Défaut : tv.

Exemple de Requête

/api/getSeasonOut?y=2023&seasons=automne&typage=tv

Données Utilisateur

GET/api/getUserList

Récupère la liste d'animés d'un utilisateur MyAnimeList en fonction d'un statut.

Paramètres

NomTypeRequisDescription
uChaîneOuiPseudonyme de l'utilisateur MyAnimeList.
sEntierNonStatut des animés à filtrer. Défaut : 2.

Valeurs possibles pour le statut (s)

  • 1: Watching
  • 2: Completed (Défaut)
  • 3: On-Hold
  • 4: Dropped
  • 6: Plan to Watch
  • 7: All Anime

Exemple de Requête

/api/getUserList?u=TMCooper&s=1

Utilitaires

GET/api/botStatus

Déclenche une mise à jour et récupère le statut Discord du bot observé par discordObserver.py.

Réponse (200 OK)

{
    "id": 123456789012345678,
    "username": "NomDuBot",
    "status": "online",
    "avatar": "https://cdn.discordapp.com/...",
    "banner": null,
    "last_updated": 1678886400.0
}

Réponse d'Erreur (Timeout)

{"error": "Le bot n'a pas répondu à temps (Timeout).", "status": "timeout"}
POST/api/translate

Traduit un bloc de texte vers une langue cible en utilisant Google Translator.

Corps de la Requête (JSON)

CléTypeRequisDescription
textChaîneOuiLe texte à traduire.
targetChaîneNonCode langue (ex: 'fr', 'en'). Défaut : 'fr'.

Exemple de Corps de Requête

{
    "text": "To be, or not to be, that is the question.",
    "target": "fr"
}

Réponse (200 OK)

{"translated_text": "Être ou ne pas être, telle est la question."}

Administration

POST/admin/verify

Vérifie la validité d'un mot de passe administrateur. Utilisé pour déverrouiller la page Admin.

POST/admin/update

Exécute une commande git pull sur le serveur pour mettre à jour le site, à condition que le mot de passe admin soit correct.

Endpoints Internes

GET/api/animeSearchAll

Retourne l'intégralité du fichier AllAnimeId.json. Cet endpoint est principalement utilisé en interne par la fonction de recherche /api/getAnimeSearch pour éviter de lire le fichier disque à chaque requête.
